# Physical AI & Humanoid Robotics

Welcome to the **Physical AI & Humanoid Robotics** textbook — an AI-native learning experience designed for the next generation of robotics engineers.

## What You'll Learn

This textbook covers the full stack of modern humanoid robotics, from low-level robot operating systems to high-level AI-powered planning and natural language interaction. By the end, you will be able to design, simulate, train, and deploy an autonomous humanoid robot.

## The Four Modules

| Module | Focus | Key Technologies |
|--------|-------|-----------------|
| **Module 1: ROS 2 Fundamentals** | Robot software architecture | ROS 2, rclpy, URDF, TF2 |
| **Module 2: Digital Twin Simulation** | Simulation & visualization | Gazebo, Unity, SDF |
| **Module 3: NVIDIA Isaac Platform** | AI perception & RL | Isaac SDK, Isaac Gym, Jetson |
| **Module 4: VLA Robotics** | Language-driven robotics | Whisper, LLMs, VLA models |

## How to Use This Textbook

1. **Follow the modules in order** for a structured 13-week learning path, or jump to any module that interests you.
2. **Run every code example** — all examples are executable with the documented dependencies.
3. **Use the AI chatbot** — click the chat icon on any page to ask questions about the material.
4. **Complete the knowledge checks** at the end of each chapter to test your understanding.
5. **Build the capstone project** to integrate everything you've learned.

## Prerequisites

- **Python 3.11+** — all code examples use Python
- **Ubuntu 22.04 or 24.04** — recommended for ROS 2 and Gazebo
- **Basic programming experience** — variables, functions, classes, and command-line usage
- **Optional**: NVIDIA GPU for Isaac modules, Jetson Orin Nano for edge deployment
