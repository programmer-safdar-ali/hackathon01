# 13-Week Learning Schedule

This schedule maps all four modules to a structured 13-week curriculum. Each week targets **8-10 hours of study**, totaling approximately **104-130 hours** for the full program.

## Schedule Overview

| Week | Module | Chapter(s) | Focus | Hours |
|------|--------|-----------|-------|-------|
| 1 | Module 1 | ROS 2 Architecture | ROS 2 fundamentals, DDS, workspace setup | 8-10 |
| 2 | Module 1 | Nodes & Topics | Publishers, subscribers, QoS profiles | 8-10 |
| 3 | Module 1 | Services & Actions, Python Packages | Request-response patterns, package creation | 8-10 |
| 4 | Module 1 | URDF & Transforms | Robot description, TF2, visualization | 8-10 |
| 5 | Module 2 | Gazebo Basics | Simulation setup, world files, models | 8-10 |
| 6 | Module 2 | Physics & Sensors | Sensor plugins, physics configuration | 8-10 |
| 7 | Module 2 | Unity Visualization, Digital Twin Pipeline | ROS-Unity integration, end-to-end pipeline | 8-10 |
| 8 | Module 3 | Isaac SDK Setup | NVIDIA Isaac installation, Jetson setup | 8-10 |
| 9 | Module 3 | Perception Pipeline | Object detection, pose estimation | 8-10 |
| 10 | Module 3 | Reinforcement Learning, Sim-to-Real | RL training, domain randomization, transfer | 8-10 |
| 11 | Module 4 | Conversational Robotics, Whisper Voice | NLU, speech-to-text, voice commands | 8-10 |
| 12 | Module 4 | LLM Planning, VLA Integration | Task planning, multimodal AI | 8-10 |
| 13 | Capstone | Capstone Project | Full integration project | 8-10 |

## Weekly Breakdown

### Week 1: ROS 2 Architecture
- Read: ROS 2 Architecture chapter
- Practice: Install ROS 2 Humble, create your first workspace
- Exercise: Write and run a minimal ROS 2 node
- Knowledge Check: Complete the chapter quiz

### Week 2: Nodes & Topics
- Read: Nodes & Topics chapter
- Practice: Create a publisher and subscriber pair
- Exercise: Build a multi-node system with custom messages
- Knowledge Check: Complete the chapter quiz

### Week 3: Services, Actions & Python Packages
- Read: Services & Actions chapter + Python Packages chapter
- Practice: Implement a service server and client
- Exercise: Create a complete ROS 2 Python package with launch files
- Knowledge Check: Complete both chapter quizzes

### Week 4: URDF & Transforms
- Read: URDF & Transforms chapter
- Practice: Write a URDF for a simple robot arm
- Exercise: Visualize your robot in RViz with TF2 transforms
- Knowledge Check: Complete the chapter quiz

### Week 5: Gazebo Basics
- Read: Gazebo Basics chapter
- Practice: Install Gazebo Fortress, load a sample world
- Exercise: Spawn your URDF robot in Gazebo
- Knowledge Check: Complete the chapter quiz

### Week 6: Physics & Sensors
- Read: Physics & Sensors chapter
- Practice: Add camera, lidar, and IMU sensors to your robot
- Exercise: Read sensor data via ROS 2 topics
- Knowledge Check: Complete the chapter quiz

### Week 7: Unity & Digital Twin
- Read: Unity Visualization + Digital Twin Pipeline chapters
- Practice: Set up Unity Robotics Hub with ROS-TCP-Connector
- Exercise: Build a basic digital twin dashboard
- Knowledge Check: Complete both chapter quizzes

### Week 8: Isaac SDK Setup
- Read: Isaac SDK Setup chapter
- Practice: Install Isaac SDK (or Isaac Sim on workstation)
- Exercise: Run a sample Isaac application
- Knowledge Check: Complete the chapter quiz

### Week 9: Perception Pipeline
- Read: Perception Pipeline chapter
- Practice: Run object detection with Isaac ROS
- Exercise: Integrate perception output with ROS 2 planning
- Knowledge Check: Complete the chapter quiz

### Week 10: RL & Sim-to-Real
- Read: Reinforcement Learning + Sim-to-Real Transfer chapters
- Practice: Set up an Isaac Gym environment
- Exercise: Train a simple manipulation policy and evaluate transfer
- Knowledge Check: Complete both chapter quizzes

### Week 11: Conversational Robotics & Voice
- Read: Conversational Robotics + Whisper Voice Integration chapters
- Practice: Build a simple intent classifier
- Exercise: Integrate Whisper for voice-controlled robot commands
- Knowledge Check: Complete both chapter quizzes

### Week 12: LLM Planning & VLA
- Read: LLM Task Planning + VLA Integration chapters
- Practice: Use an LLM to generate robot task plans
- Exercise: Build a multimodal VLA inference pipeline
- Knowledge Check: Complete both chapter quizzes

### Week 13: Capstone Project
- Read: Capstone Project Overview and Steps
- Build: Integrate all four modules into an autonomous humanoid robot
- Validate: Complete all checkpoint validations
- Present: Document and demo your capstone project

## Pacing Tips

- **Falling behind?** Focus on the code examples and knowledge checks — skip the deep-dive sections and return later.
- **Moving ahead?** Explore the hardware guides and try running code on physical hardware.
- **Working in a team?** Assign different modules to team members and integrate during the capstone week.
